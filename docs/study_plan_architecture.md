# معماری جامع و مشخصات فنی فیچر برنامه مطالعه قرآن (Study Plan)

این سند مشخصات فنی، معماری داده، الگوریتم‌های محاسبه پیشرفت و یکپارچه‌سازی فیچر «برنامه مطالعه قرآن» را در اپلیکیشن قرآن تفکر تشریح می‌کند.

---

## ۱. اهداف و فلسفه طراحی (Product & UX Philosophy)

1. **انعطاف‌پذیری در انتخاب نوع برنامه**:
   - **برنامه با دوره مشخص (Fixed Days)**: مثلاً ختم ۱۰ روزه، ۳۰ روزه یا ۶۰ روزه با سهمیه روزانه مشخص (بر اساس صفحه، حزب، جزء یا سوره).
   - **برنامه روزانه مستمر (Continuous Daily)**: تعهد روزانه دائمی (مثلاً روزی ۲ صفحه یا ۱ حزب به صورت پیوسته و بدون پایان زمانی).
2. **محاسبه دقیق و بدون باگ پیشرفت (Bug-Free Progress Tracking)**:
   - تشخیص خواندن جزئی (مثلاً خواندن ۲ صفحه از سهمیه ۵ صفحه‌ای امروز = ۴۰٪ پیشرفت امروز).
   - عدم تداخل مطالعه تصادفی سایر سوره‌ها با بازه فعال برنامه مطالعه.
   - پایش روز تقویمی جدید و مدیریت هوشمند جابه‌جایی صفحات و زنجیره تداوم (Daily Streak).
3. **دسترسی دومنظوره (Omnipresent Selection)**:
   - امکان مشاهده، ایجاد و انتخاب برنامه فعال از **صفحه اختصاصی برنامه‌ها (`/study-plans`)**.
   - امکان مشاهده، سوییچ و پرش به صفحه سهمیه امروز مستقیم از **صفحه قرائت قرآن (`Quran Reader`)**.
4. **تشویق و انگیزش (Celebration & Notification)**:
   - تشخیص لحظه‌ای اتمام سهمیه امروز و ارائه فیدبک تشویقی (اعلان/بنر جشن تکمیل هدف امروز).

## ۲. مدل داده و ذخیره‌سازی محلی (Hive Schema)

تمام برنامه‌ها در دیتابیس محلی Hive درون باکس `study_plans_box` ذخیره می‌شوند.

### فیلدهای انتیتی `StudyPlan`:

```dart
class StudyPlan {
  final String id;                    // شناسه یونیک (Timestamp)
  final String title;                 // عنوان برنامه
  final StudyPlanType type;           // continuousDaily یا fixedDays
  final bool isOngoing;               // آیا روزانه دائمی است؟
  final StudyPlanUnit unit;           // page, hizb, juz, surah
  final int unitAmount;               // مقدار واحد انتخابی (مثلاً ۲ صفحه یا ۱ حزب)
  final int targetDays;               // تعداد روزهای دوره (در دائمی = ۰)
  final int dailyPagesTarget;         // تعداد صفحات معادل سهمیه روزانه
  final int totalPages;               // کل صفحات هدف دوره (حداکثر ۶۰۴)
  final DateTime startDate;           // تاریخ شروع
  final DateTime targetEndDate;       // تاریخ پایان موعد دوره
  
  // پیشرفت کلی
  final int completedPagesCount;      // کل صفحات تکمیل‌شده در این برنامه
  final StudyPlanStatus status;       // active, inactive, completed, expired

  // پیشرفت سهمیه امروز (Daily Slice)
  final int todayStartPage;           // شماره صفحه شروع سهمیه امروز
  final int todayEndPage;             // شماره صفحه پایان سهمیه امروز
  final int todayCurrentPage;         // آخرین صفحه خوانده‌شده در بازه امروز
  final bool isTodayCompleted;        // آیا سهمیه امروز تکمیل شده است؟
  
  // زنجیره تداوم و زمان‌بندی
  final DateTime? lastReadDate;       // آخرین روزی که مطالعه ثبت شد
  final int streakDays;               // تعداد روزهای متوالی انجام هدف
  final DateTime createdAt;           // زمان ساخت رکورد
}
```

کلید متادیتا در هایو:
- `_active_plan_id_meta_key`: شناسه برنامه‌ای که هم‌اکنون به عنوان برنامه فعال کاربر انتخاب شده است.

## ۳. الگوریتم محاسبه پیشرفت و تغییر روز (Progress Engine)

### الف) منطق ثبت صفحه در حین قرائت (`recordPageRead`)
برای جلوگیری از باگ پرش صفحات متفرقه:
1. سیستم بررسی می‌کند آیا شماره صفحه بازشده (`pageNumber`) دقیقاً در بازه سهمیه امروز برنامه فعال (`todayStartPage` تا `todayEndPage`) قرار دارد یا ادامه توالی خوانده‌شده است.
2. صفحات خارج از محدوده (مثلاً اگر کاربر برنامه جزء ۱ دارد ولی سوره کهف صفحه ۲۹۳ را باز کند) باعث اتمام اشتباه برنامه نخواهند شد.
3. با خواندن صفحات بازه امروز:
   $$\text{doneToday} = \max(0, \text{pageNumber} - \text{todayStartPage} + 1)$$
   $$\text{todayProgress} = \min(1.0, \frac{\text{doneToday}}{\text{todayEndPage} - \text{todayStartPage} + 1})$$
4. اگر $\text{pageNumber} \ge \text{todayEndPage}$:
   - مقدار `isTodayCompleted = true` می‌شود.
   - رویداد تشویق (`Goal Celebration`) منتشر می‌شود.

### ب) سناریوی روز بعد (Day Roll-Over) و استریک:
هنگام ورود کاربر به برنامه در یک روز تقویمی جدید:
1. **اگر کاربر دیروز هدف را کامل کرده بود (`isTodayCompleted == true`)**:
   - سهمیه امروز به صفحات بعدی منتقل می‌شود:
     $$\text{todayStartPage}_{\text{new}} = \text{completedPagesCount} + 1$$
     $$\text{todayEndPage}_{\text{new}} = \min(\text{totalPages}, \text{todayStartPage}_{\text{new}} + \text{dailyPagesTarget} - 1)$$
   - `isTodayCompleted` برای روز جدید `false` می‌شود.
2. **اگر کاربر دیروز هدف را کامل نکرد یا اصلاً نخواند**:
   - کاربر جریمه نمی‌شود؛ سهمیه امروز از همان آخرین صفحه نخوانده ادامه می‌یابد.
   - اما استریک روزانه (`streakDays`) بازنشانی به ۱ یا ۰ می‌شود (در صورت انقطاع بیش از ۱ روز).

## ۴. نحوه نمایش درصدها در UI

### ۱. برنامه با دوره مشخص (Fixed Days):
- **حلقه پیشرفت روی کارت هوم**: پیشرفت **کل دوره** را نشان می‌دهد:
  $$\text{Overall Progress} = \frac{\text{completedPagesCount}}{\text{totalPages}} \times 100\%$$
- **متن زیر کارت**: وضعیت امروز را دقیقاً بیان می‌کند:
  - «امروز: صفحه ۱ تا ۵ (۳ از ۵ صفحه) • ۲۵٪ کل دوره»
  - وقتی هدف امروز تمام شد: «هدف امروز تکمیل شد (۵ از ۵) • تیک سبز».

### ۲. برنامه روزانه مستمر (Continuous Daily):
- **حلقه پیشرفت روی کارت هوم**: پیشرفت **سهمیه امروز** را نشان می‌دهد:
  - مثلاً سهمیه ۲ صفحه است و ۱ صفحه خوانده: **۵۰٪**.
  - وقتی هر ۲ صفحه خوانده شد: **۱۰۰٪ با تیک سبز**.
- **متن کارت**: نمایش استریک تداوم و کل پیشرفت قرآن:
  - «امروز تکمیل شد • 🔥 ۵ روز پیوسته • صفحه ۴۵ از ۶۰۴ قرآن».

## ۵. تعامل درون صفحه قرآن‌خوان (Quran Reader Integration)

1. **کپسول برنامه مطالعه در بالای صفحه قرائت** (در `QuranInfoBar` یا اکشن بالای صفحه):
   - نمایش سریع: `[ 📖 برنامه فعال: ۲ از ۵ صفحه امروز ]`.
   - با کلیک روی آن، باتم‌شیت سریع باز می‌شود که:
     - نام و مشخصات برنامه فعال را نشان می‌دهد.
     - دکمه پرش به صفحه سهمیه امروز را دارد.
     - دکمه تغییر برنامه فعال یا غیرفعال‌سازی موقت را دارد.
2. ثبت بدون وقفه پیشرفت به محض ورق زدن صفحات سهمیه.

---

## ۶. سیستم اعلان و جشن تکمیل هدف روزانه (Goal Celebration)

به محض اینکه کاربر آخرین صفحه سهمیه روزانه را ورق بزند:
1. `isTodayCompleted` فعال می‌شود.
2. `streakDays` افزایش می‌یابد.
3. یک اعلان درون‌برنامه‌ای زیبا با انیمیشن ملایم نمایش داده می‌شود:
   > **«تبارک‌الله! 🎉 هدف امروز برنامه مطالعه‌ات را با موفقیت تکمیل کردی.»**
